# Roadmap Implementation Map

1. Frontend foundation — Vite public site, reusable React portals, accessibility and SEO.
2. UI/UX/SEO/performance — responsive public experience, metadata, robots, sitemap, manifest, reduced motion.
3. Product catalog — structured product model, search/filter frontend, product REST endpoints.
4. Express backend — versioned API, middleware, validation, error handling, health route.
5. MongoDB — Mongoose models, indexes and seed script.
6. Authentication/RBAC — bcrypt, JWT, customer/admin authorization and portals.
7. CRM — enquiries, statuses, ownership and admin management endpoint.
8. Admin operations — dashboard metrics, customers, enquiries and inventory portal.
9. Inventory — movement model, stock changes and low-stock detection.
10. Orders — order lifecycle, ownership and stock deduction.
11. Security hardening — Helmet, CORS, rate limits, validation, safe errors and security documentation.
12. Testing — Node test runner, syntax/lint checks and testing documentation.
13. Performance — Vite production build, compression, pagination, indexes and performance notes.
14. Deployment — environment example and deployment checklist.
15. Final audit — architecture, security, testing and known limitations documented.
